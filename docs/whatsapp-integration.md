# WhatsApp Business Platform integration

Kondai connects to WhatsApp through Meta's Cloud API.

## What it can receive

After Meta verifies the webhook, Kondai receives new customer messages sent to
the connected WhatsApp Business Platform number. Each message is saved inside a
conversation and linked to a customer issue.

The connector supports text, buttons, interactive replies, images, video,
documents, audio, voice notes, stickers, locations, reactions and contact-card
placeholders. Media IDs are retained for a later download feature.

## What it cannot do

Kondai cannot silently read ordinary personal WhatsApp chats from a phone.

Existing chat history is not generally available through a normal Cloud API
connection. New inbound messages are the dependable integration path. Some
special WhatsApp Business App coexistence onboarding flows can emit history
events, but this build does not claim or depend on that behaviour.

## Meta setup

1. Create a Meta Business app.
2. Add the WhatsApp product.
3. Add or onboard a WhatsApp Business phone number.
4. Create a permanent system-user access token with the required WhatsApp
   permissions.
5. Copy the Phone Number ID and WhatsApp Business Account ID.
6. In Kondai Connections, enter those values, the access token, the Meta App
   Secret, a private verify token and the public HTTPS backend URL.
7. Copy the callback URL generated by Kondai.
8. Open Meta App Dashboard → WhatsApp → Configuration.
9. Paste the callback URL and the same verify token.
10. Subscribe to the `messages` webhook field.
11. Send a test WhatsApp message to the business number.

## Local development

Meta needs a public HTTPS callback. Expose FastAPI with a secure tunnel:

```powershell
ngrok http 8000
```

Use the generated HTTPS address as the public backend URL in Kondai.

## Reply safety

Inbound messages create customer issues automatically.

Kondai drafts replies from verified product information, but the reply must be
approved before it is sent. Free-form replies are limited to the customer
service window after the customer's most recent message. Outside that window,
an approved WhatsApp template is required; template sending is intentionally
not implemented in this patch.
